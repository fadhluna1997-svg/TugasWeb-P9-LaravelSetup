# Tugas Web P9 - Laravel Setup

## Identitas

- Nama: Luna
- Mata Kuliah: Pemrograman Web
- Pertemuan: 9
- Framework: Laravel 11
- PHP: 8.2
- Database: MySQL

## Deskripsi

Project ini dibuat untuk memenuhi tugas Pertemuan 9 pada mata kuliah Pemrograman Web.

Project menggunakan Laravel dan menerapkan konsep dasar Laravel seperti:

- Composer
- Routing
- Controller
- Blade Template
- Model
- Migration
- Database MySQL
- Eloquent ORM
- Tinker
- MVC (Model View Controller)

## Teknologi yang Digunakan

- PHP 8.2
- Laravel 11
- Composer
- MySQL
- phpMyAdmin
- Visual Studio Code
- XAMPP
